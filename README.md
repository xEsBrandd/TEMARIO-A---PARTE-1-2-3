# TEMARIO-A---PARTE-1-2-3
Repositorio que alojara la programación de clases y el UML
Descripción: El sistema es un dashboard desarrollado en Java que reúne widgets de clima, tareas, alertas, relojes y frases.

Objetivos: Gestionar los widgets mediante interfaces y polimorfismo, permitiendo buscarlos, ordenarlos por memoria e interactuar con los que admiten acciones.

Desarrollo: Se utilizó Java Swing para la interfaz gráfica y el patrón MVC para organizar el código, generado por dos entregas principales, Parte 1 y 2.

Conclusión: Se obtuvo un sistema modular que permite incorporar nuevos widgets sin modificar la lógica principal del dashboard.
